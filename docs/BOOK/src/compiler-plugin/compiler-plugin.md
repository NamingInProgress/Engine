# VKECompilerPlugin
**vke** uses a java compiler plugin to ease with certain boring tasks or optimize
certain processes.

As of right now [VKECompilerPlugin](https://github.com/NamingInProgress/VKECompilerPlugin) has the features listed below:
- [ECS Component Creation](ecs.md)
- [Vertex Format Creation](vertex.md)
- [Annotation Searching](annotation-search.md)
