each app can have a
resources/<namespace>/assets
directory which will be the root of the asset tree
assets/global
is the global bundle that will always be loaded
each other directory in assets will be a separate asset bundle
which may contain a bundle.xml file.
this xml file will contain resources, that arent related to any on-disk files like
strings, ints, bools and colors.
